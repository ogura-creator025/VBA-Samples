# VBA-Samples

Excel VBAで作成した実用的なサンプルコード集です。

## `IsPrime.bas`（素数判定関数）
引数で渡された数値が素数かどうかを判定するFunction関数です。

#### ✨ 特徴
- **高速化処理**: 偶数の除外および平方根までの試し割りにより無駄な計算をカット
- **汎用性**: モジュールに組み込むだけで汎用的に利用可能
- **シンプル構造**: 可読性が高くメンテナンスしやすいコード

#### 💡 判定アルゴリズム
1. `1` 以下は素数ではない（`False`）
2. `2` と `3` は素数（`True`）
3. 偶数は除外（`False`）
4. `3` から平方根まで奇数のみで割り切れるか判定

## 💻 動作環境

- Microsoft Excel (VBA)
- Office 2016 以降（それ以前のバージョンでも動作可能）
